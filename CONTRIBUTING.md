# Contributing to AttoLang

Read the [AOT/zero-GC controlled-dynamism policy](docs/AOT_ZERO_GC_DYNAMISM_POLICY.md) when editing language docs, compiler integrations, playground features, runtime/actor behavior or examples. Specify build/execution profile, reachable static dispatch/proxy targets, ownership/cleanup and memory claim. Add positive and negative `.atto` tests and real backend execution before claiming parity. Preserve separate approval/security, Rust-only tooling and existing deployment safeguards.
